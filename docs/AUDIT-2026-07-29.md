# Registry audit — 2026-07-29

## Scope

This audit covers the verified primary catalog in `models/registry.yaml`. The inclusion boundary is now **total parameters at or below 12B** (`0 < total_b <= 12`), measured using the developer’s published total count or live Hugging Face safetensors metadata when available. Active parameters do not substitute for total parameters.

| Verified primary records | 92 | 144 |

| Edge exceptions | 0 | 7 |

| Largest primary record | <12B policy | 12.0B boundary |

The catalog now includes language, coding, vision-language, OCR, audio, embodied, and research-oriented model records. The 12B boundary is represented explicitly by Gemma 4 12B Unified variants and EleutherAI Pythia 12B; their inclusion depends on the inclusive policy and their published/live total counts.

The subsequent quality checkpoint expanded the primary catalog to 165 records, added 21 high-confidence models, corrected the audited factual records, and introduced field-level `evidence` objects for 28 new or corrected records. The remaining legacy records are an explicit evidence-migration backlog.

## Metadata debt identified

The parameter/provenance audit is complete, but 91 records still have a null `release_date`. This is retained as explicit unknown metadata rather than guessed from Hub creation timestamps. A follow-up pass should fill those dates from release announcements or model cards. Five live Hub records also expose only a generic `other` license label even though the registry preserves a more specific license name from the official documentation; these are warnings, not parameter failures.

## Remaining review queue

`internlm/Intern-S2-Mobius` was created on 2026-07-29, but its Hub repository did not yet expose weights, configuration, or a verifiable parameter count during this audit. It should remain a review candidate until those artifacts are published.
